连接前检查

1. 进入配置窗口 重启 mote 或触发一次 motion。蓝灯闪烁时约 30 秒可连接。
2. 使用 Chrome 请用 Android Chrome 或桌面 Chrome。不要使用 iOS Safari 或微信内置浏览器。
3. 保存后复核 保存成功后点读取配置。重启后再次读取，应保持同一参数。
灵敏度预设
保存配置会写入 mote 并持久化；重启后仍应保持。
高级参数 THS=0x03 DUR=0x21
范围 0..63。数值越小越容易触发。 THS 必须是 0 到 63 的整数。
范围 0..255。默认 0x21 用于当前事件型检测。 DUR 必须是 0 到 255 的整数。
